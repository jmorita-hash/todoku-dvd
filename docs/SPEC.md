# DVD の仕様（サイト掲載の注釈との対応）

サイトに載せている注釈と、アプリがそれをどう実現しているかの対応表。
**注釈を変えるときは、この表とアプリの設定もあわせて見直すこと。**

| サイトの注釈 | アプリでの実現方法 | 設定・場所 | 自動テスト |
|---|---|---|---|
| 映像は「オーサリング」をしております | dvdauthor で DVD-Video の構成（VIDEO_TS / IFO / VOB）を作る | `lib/dvd.sh`、`templates/dvd.xml` | 組み立て成功・IFO の存在 |
| 映像は「ファイナライズ」をしております | 書き込み時に `hdiutil burn -forceclose` でディスクを閉じる | `lib/disc.sh` | ×（ドライブが必要） |
| NTSC 方式です | 720x480・29.97fps・MPEG-2 で変換 | `TV_STANDARD="ntsc"` | 映像形式の確認 |
| リージョンフリーです | リージョン制限なし（VIDEO_TS.IFO のリージョンマスク = 00） | dvdauthor の既定 | リージョンマスク確認 |
| DVD-R を使用しております | 書き込み前にディスクの種類を確認し、DVD-R 以外（DVD+R、DVD-RW、CD-R など）は止める | `DISC_TYPES="DVD-R"` | ×（ドライブが必要） |
| Video 形式で書き込みいたします | DVD-Video 形式（UDF 1.02 + ISO9660）のディスクイメージを書き込む | `lib/disc.sh` | ISO の中身確認（Mac のみ） |
| 前後に 10 秒無地画面を配置（秒数の変更可能） | 既定 10 秒の無地画面（黒）＋無音を前後に付ける。作業時に1本ごとに秒数を入力できる（0〜60秒） | `PAD_SEC=10`、`PAD_SEC_MAX`、`PAD_COLOR` | 長さ・先頭/末尾が無地か |
| リピート再生はオフ | 本編の最後で `exit`（再生停止）。最初に戻らない | `END_ACTION="stop"` | 設定の確認 |
| メニュー画面は使用しておりません | メニューを作らず、ディスクを入れたら本編を自動再生（First Play → タイトル1） | `templates/dvd.xml` | ― |

## 補足

- 画面比率は 16:9。16:9 以外の動画は左右（または上下）に黒帯を付けて収める。
- 音声は AC-3（ドルビーデジタル）48kHz ステレオ。音声のない動画は無音トラックを付ける。
- 画質は長さに応じて自動調整（最大 8Mbps）。目安として約1時間半までが DVD 1枚に入る。
- 焼いた DVD が家庭用プレーヤーで自動再生・停止するかは、プレーヤーの機種によって動きが違うことがある。
  発送前の再生確認は必ず行う。
